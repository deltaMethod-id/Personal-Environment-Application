## 📖 Overview

Personal Environment is a privacy-focused web application designed to securely store personal information in one protected place.

Store API keys, passwords, access tokens, notes, source code, URLs, and other confidential information behind multiple layers of protection.

Everything is built with security and simplicity in mind.

---

## ✨ Features

### 🔐 Security

- Password Authentication
- PIN Authentication
- Fingerprint Authentication (Supported Browsers)
- Auto Lock
- Local Encryption
- Secure Session

---

### 📝 Personal Text

Store:

- API Keys
- Access Tokens
- Passwords
- Notes
- URLs
- Source Code
- Personal Information

Every Personal Text is hidden by default.

```
••••••••••••••••••••
```

Actions:

- 👁 Show
- 📋 Copy
- ✏ Edit
- 🗑 Delete

Password verification is required before:

- Showing content
- Copying content
- Deleting content

## ⚠ Important Notice

Personal Environment v1.2 introduces a new storage format for Personal Text.

Sensitive data from previous versions is **NOT automatically migrated**.

Before updating:

1. Copy all sensitive data.
2. Update to v1.2.
3. Create new Personal Text entries.
4. Paste your previous data.

Failure to back up your data before updating may result in permanent data loss.
